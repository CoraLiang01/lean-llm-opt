##### Objective Function

\[
\min \sum_{i=1}^{11} \sum_{j=1}^{11} c_{ij} x_{ij} + \sum_{i=1}^{11} f_i y_i
\]

##### Constraints

1. **Demand satisfaction:**  
   For each store $j$,
   \[
   \sum_{i=1}^{11} x_{ij} = d_j \qquad \forall j = 1,\ldots,11
   \]

2. **Warehouse capacity:**  
   For each warehouse $i$,
   \[
   \sum_{j=1}^{11} x_{ij} \leq u_i y_i \qquad \forall i = 1,\ldots,11
   \]

3. **Variable domains:**  
   \[
   x_{ij} \geq 0 \quad \text{(continuous)}, \qquad y_i \in \{0,1\}
   \]
