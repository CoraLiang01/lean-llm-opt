##### Decision Variables

- $x_{ij} \geq 0$: Quantity shipped from warehouse $i$ to store $j$ (continuous).
- $y_i \in \{0,1\}$: 1 if warehouse $i$ is opened, 0 otherwise.

##### Objective Function

\[
\min \sum_{i=1}^{11} \sum_{j=1}^{11} c_{ij} x_{ij} + \sum_{i=1}^{11} f_i y_i
\]

##### Constraints

1. **Demand Satisfaction:**  
   Each store's demand must be fully met:
   \[
   \sum_{i=1}^{11} x_{ij} = d_j \quad \forall j = 1,\ldots,11
   \]

2. **Warehouse Capacity:**  
   Shipments from each warehouse cannot exceed its capacity if opened:
   \[
   \sum_{j=1}^{11} x_{ij} \leq u_i y_i \quad \forall i = 1,\ldots,11
   \]

3. **Variable Domains:**  
   \[
   x_{ij} \geq 0 \quad \forall i, j
   \]
   \[
   y_i \in \{0,1\} \quad \forall i
   \]

- $J = \{1,2,\ldots,11\}$ (stores)
