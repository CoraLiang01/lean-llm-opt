# WL 结构相似度：统一边界表示与边界排除的对照

## 结论

在本次数据上，将所有单变量限制统一转入 Bounds 并排除出 WL 图，确实使各类别的最近同类别参考相似度中位数降低。101 个实例的总体中位数从 **0.7271** 降至 **0.5065**；36 个 Variants 从 **0.6793** 降至 **0.4325**。这说明相似度依赖于图编码采用了哪些信息，并不意味着数学模型因为改变存储位置而变得更不相似。

应先确定衡量目标，再选择编码。不能因为某个编码产生较低分数，就将它作为更强的泛化证据。两组结果均保留，建议共同报告。

## 数据与类别

本次使用当前文件中的 15 个 RefData 模型、101 个原始测试模型、36 个 Variants。RefData 的类别按 `Large_Scale_Or_Files/RAG_Examples_All.csv` 映射，Variants 按当前 `benchmark_dataset/questions.csv` 中的 Variant 编号映射，不按 CSV 行号猜测编号。

RefData 类别池分别为：NRM、RA、TP、AP、UFLP 各 1 个参考；Mixture 8 个；Others 2 个。Mixture 的同类别比较仅检索 Mixture，不合并 Others。

## 两种统一处理方式

两种处理均先读取原模型，找出恰有一个非零项的约束。例如 `2x <= 6` 转为 `x <= 3`；负系数时翻转不等号；单变量等式转为相同的上下界。再将这些限制与原有有限上下界取交集：下界取最大值，上界取最小值。这样不会重复统计同一变量上的较弱或重复边界。

- **纳入边界：** 每个有效有限下界、上界各输出一条显式约束，参与 WL 图。默认非负下界和二元变量的 0/1 界也同样处理。连续、一般整数变量在 Bounds 中写为 `free`，避免暗中重复限制；二元变量保留其二元域声明。
- **排除边界：** 有效边界全部写入 Bounds，删除原单变量约束行，不生成对应的约束节点。整数域的界按 `ceil(lower)`、`floor(upper)` 表示，例如整数变量 `x <= 31.7` 与 `x <= 31` 可行取值完全相同。这也避免 LP 读取器自动舍入整数界造成表面上的数值不一致。

两个版本都保留其余约束、变量域、目标函数、方向、常数及多目标优先级等参数。固定变量仍保留，不进行一般 presolve，也不删除孤立变量。没有从多变量约束中继续推导隐含边界。因此，这是一种针对边界和单变量行的统一处理，并非所有等价数学写法的完全规范化。

例如，原来的写法可能是：

```text
Subject To
  cap: x <= 3
  coupling: 2 x + y <= 5
Bounds
  x >= 0
  y >= 0
```

排除边界的统一写法是：

```text
Subject To
  coupling: 2 x + y <= 5
Bounds
  0 <= x <= 3
  0 <= y <= +inf
```

`x <= 3` 仍然限制可行解，只是不进入用于诊断的图。不能只删除约束而不保留对应的 Bounds。

## WL 的定义保持一致

两个版本都使用变量—约束二部图，变量标签为 `V:B/I/C`，约束标签为 `R:E/I`；每个非零矩阵项产生一条边。所有变量节点保留，即使没有邻居。约束系数、符号、RHS、目标值和名称不参与 WL；排除版还不包含边界节点或边界数值。

使用 Shervashidze et al. (2011) 的 WL subtree 特征构造：每轮用“旧标签 + 邻居旧标签的排序多重集”生成共享的新标签，统计第 0 至第 h 轮的标签数量，拼接为特征向量。主结果固定为 h=2，另报告 h=1、3。相似度为拼接特征向量的余弦归一化内积：

\[
S_h(G,G')=\frac{k_{\mathrm{WL}}^{(h)}(G,G')}{\sqrt{k_{\mathrm{WL}}^{(h)}(G,G)k_{\mathrm{WL}}^{(h)}(G',G')}}.
\]

**WL 原论文没有规定优化模型的 Bounds 必须放在哪、是否参与图编码。** 原论文定义的是给定带标签图上的核；优化模型到图的转换规则，以及这里的余弦归一化，是本文明确规定的应用选择。因而不能称“排除 Bounds”是 WL 原论文要求的标准优化模型处理。

参考：[Shervashidze et al. (2011), Weisfeiler–Lehman Graph Kernels, JMLR](https://jmlr.csail.mit.edu/papers/volume12/shervashidze11a/shervashidze11a.pdf)。

对于每个测试实例，先在相应类别的参考池中取最大相似度，再对这些最近参考分数计算中位数与均值。全参考库列则对全部 15 个参考取最大值。“全部”行是所有实例的汇总，不是类别中位数的平均值。无该类别测试实例时显示“—”，不能读作相似度为 0。分数越高表示所选图特征越接近，不代表求解准确率。

## 为什么分数降低，以及如何用于 AE 回复

**共同的边界节点会贡献相似性。** 多数模型都包含非负变量、二元域或其他有限界。纳入这些边界后，每个变量周围增加一些相同标签的叶子节点，使很多局部标签计数更接近。排除版关注的是变量在多变量约束中的耦合关系；它测量的信息范围更窄。因此，较低分数并不是一个无需解释的更好结果。

**NRM 尤其需要单独解释。** 25 个 NRM 的所有显式约束原本都是变量各自的库存/需求限制。转入 Bounds 后，它们都保留变量节点，但没有约束节点或边。当前 NRM 参考 Ref03 还包含此前添加的 `dispatch_capacity` 共享容量约束，连接 4 个变量。因而，在 h=2 时，测试和参考的第 0 轮仍共享整数变量标签，第 1、2 轮的“孤立变量”和“连着容量约束的变量”标签无法匹配，得到 0.3234。

作为解释性对照，本次只在一个独立副本中去掉 Ref03 的这条共享容量行：25 个 NRM 的分数全部恢复到 **1.0000**。这未修改原参考文件。因此，该低分主要反映“有无这条耦合约束”，而不是证明 25 个测试 NRM 自身具有丰富的结构多样性。当前 Ref03 是先前调整过的参考，不能将这一对照描述成独立于相似度分析而预先固定的验证。

**AP 的低分也不能直接当作业务新颖性。** 原始 5 个 AP 的变量是连续型，AP 参考是二元型。类型标签会影响每轮 WL 标签传播，尽管标准指派模型的连续写法在适当条件下可能与整数写法具有相同最优目标值。排除 Bounds 不会消除这一变量域编码差异。

**总体中位数不是低重合的统计检验。** WL 没有针对这些优化模型校准过的“高/低”通用阈值，0.5065 也不是“50.65% 的约束相同”。分数 1 仅说明归一化特征相同；不同大小、不同可行域或不同目标的模型也可能得到 1。Mixture 参考池有 8 个候选，比其他类别更多，取最近参考本身更容易获得高值。

**建议回复审稿人时同时报告两种编码。** 可以将排除版称为“仅考察多变量约束耦合结构的 WL 诊断”，纳入版称为“将边界表示纳入的敏感性分析”。它们说明参考与测试的局部图特征并非全部一致，也明确揭示表示方式的影响。不能据此排除共享模板，也不能单独证明对新增约束、不同目标或新业务需求的求解鲁棒性；后者需要固定参考池的变种性能、LOTO 和 routing 实验结果。

两组数据的类别构成不同：Variants 没有 NRM/RA/TP。不能只比较两个总体中位数，就断言每个变种均比其原始问题更复杂或相似度更低。

## 有效性检查

- 两种转换各覆盖全部 152 个模型，原始 LP 和 3 个输入 CSV 的哈希均未变化。
- 两种转换均核对变量域、有效边界、保留约束的系数/RHS、目标常数/方向及多目标参数；每个导出的 LP 与 MPS 都完成重新读入核对。
- 纳入版另通过 152 个模型的再次规范化核对，并通过“原生 Bounds、显式边界行、缩放/重复边界行”三个等价例子的 WL 一致性检查。
- 纳入版的原始/转换模型均找到可行解；151 对求得相同最优目标值。Others/Other6 在每个模型 20 秒的限时内未证明最优，但两边都有可行解、目标值在核对容差内一致。延长至 30 秒后仍有约 0.1253% 的最优性缺口。不能声称全部 152 对都已证明最优。
- 排除版通过与原始模型及纳入版的可行域签名核对。唯一需要把分数上下界化为整数界的实例是 Mixture10 的 100 个整数变量；其原始模型与排除版另外做求解核对。
- 本次没有重跑 LLM 的准确率实验。优化模型等价检查不等同于 LLM 的鲁棒性或求解准确率检查。

目标常数使用 Gurobi 的 `Constant = 1` 序列化约定。这个特殊符号读取后折叠为目标偏移，不是参与 WL 的新增决策变量。参考：[Gurobi 关于目标常数的 LP 编码说明](https://support.gurobi.com/hc/en-us/community/posts/41718631858961-Adding-a-constant-to-the-objective-function-can-lead-to-a-bug)。
