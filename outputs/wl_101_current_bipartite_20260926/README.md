# 当前101个测试LP的typed WL二部图相似度

测试LP：generated_label_models/<类别>/<实例>/<实例>.lp，共101个，由用户提供的
label generation code生成。重算时逐个核对文件存在性，并将当前SHA256写入manifest.csv。
参考LP：Ref Data_Large_Scale_LP/1.lp至15.lp；类别取当前RAG_Examples_All.csv
对应行。NRM参考为新增共享发货容量sum(x)<=100的单期鞋类模型。

图节点为变量和约束，非零矩阵项定义边；变量标签B/I/C，约束标签等式/不等式。
不做presolve，不使用目标、系数数值/符号、RHS、边界及名称。主结果累计
WL第0、1、2轮标签计数，以归一化内积比较。h=1、3敏感性结果一并保存。

每个测试实例分别在同类别参考池和全部15个参考中取最大相似度，然后汇总。
分数越高表示这个图表示越相似，不能解释为业务内容相同的百分比。

全部实例行是对101个逐实例分数汇总，不是类别中位数的平均。
Mixture和Others是宽泛类别，不能当作单一建模原型。

特别核查：AP参考1.lp为9个二进制变量、6条等式；5个测试AP分别为144、9、
36、121、49个连续变量，均采用等式约束。typed WL会对B/C区别编码，
因此AP低分不能直接证明分配问题模板或业务要求高度不同。
这些是当前文件结果，不应与早期不同参考类别映射、不同LP版本的表混用。

文件：manifest.csv含路径、哈希、规模和类别；pairwise_h2.csv为101×15矩阵；
nearest_h2.csv含逐题同类/全库最近参考及分数；category_summary.csv含各轮
类别统计；audit.json记录计算口径。h1/h3为相同命名的敏感性文件。

复现：在仓库根目录运行 `/usr/bin/python3 recompute_wl_101.py`。
该脚本调用根目录的独立模块 `wl_bipartite.py`，不再依赖 notebook 单元顺序；
不执行API或实验单元，不更改输入LP，不进行LLM准确率实验。完整方法、与
MIPLIB 2017 的差异和引用见根目录 `WL_IMPLEMENTATION_REPORT.md`。
