# WL 方法论文与本项目实现说明

## 1. 对应的原始论文

本项目采用的 WL 方法主要对应以下论文：

> Nino Shervashidze, Pascal Schweitzer, Erik Jan van Leeuwen, Kurt Mehlhorn, and Karsten M. Borgwardt. **Weisfeiler--Lehman Graph Kernels**. *Journal of Machine Learning Research*, 12(77):2539--2561, 2011.

论文主页：[JMLR article](https://jmlr.csail.mit.edu/papers/v12/shervashidze11a.html)；论文 PDF：[PDF](https://jmlr.csail.mit.edu/papers/volume12/shervashidze11a/shervashidze11a.pdf)。

论文研究的是一种高效的图核（graph kernel），用于判断两个带有离散节点标签的图在结构和标签模式上有多相似。论文的核心思想来自 Weisfeiler--Lehman（WL）图同构检验，也称为 1-dimensional WL 或 naive vertex refinement。论文不是直接枚举所有子图，而是反复更新节点标签，把每个节点周围逐步扩大的邻域结构编码为离散标签，再比较不同图中这些标签出现的次数。

论文的主要贡献有三点：

1. 提出基于 WL 标签细化序列的一族图核，包括计算效率很高的 WL subtree kernel。
2. 给出高效的特征构造方法。对于图中的每一轮标签，只需统计标签直方图，就可以形成图的特征向量。
3. 在多个图分类数据集上验证方法。论文报告 WL graph kernels 在分类准确率和运行时间方面优于若干当时的图核基线，并指出其运行时间随图的边数和 WL 迭代轮数近似线性增长。

论文的研究对象是一般的带离散节点标签图。论文本身并没有规定如何把线性规划或混合整数规划转换为图，也没有规定 LP/MIP 的变量类型、约束类型或系数应该如何编码。将 LP/MIP 表示成变量—约束二部图，是本项目针对优化模型所做的建模适配。

## 2. 原论文中的 WL 算法

### 2.1 与原论文符号的对应关系

前一版说明使用了更适合解释代码的记号，因此与论文中的符号并非逐字一致。算法含义是一致的，但下面给出论文记号的严格对应关系。论文对第 \(i\) 轮出现的标签集合记为 \(\Sigma_i\)，其中

\[
 \Sigma_i=\{\sigma_{i1},\ldots,\sigma_{i|\Sigma_i|}\}.
\]

论文用 \(c_i(G,\sigma)\) 表示标签 \(\sigma\) 在图 \(G\) 的第 \(i\) 轮标签中出现的次数。论文定义的 WL subtree feature map 是

\[
 \phi^{(h)}_{\mathrm{WLsubtree}}(G)=
 \big(c_0(G,\sigma_{01}),\ldots,c_0(G,\sigma_{0|\Sigma_0|}),
 \ldots,
 c_h(G,\sigma_{h1}),\ldots,c_h(G,\sigma_{h|\Sigma_h|})\big).
\]

论文的 WL subtree kernel 是

\[
 k^{(h)}_{\mathrm{WLsubtree}}(G,G')
 =
 \left\langle
 \phi^{(h)}_{\mathrm{WLsubtree}}(G),
 \phi^{(h)}_{\mathrm{WLsubtree}}(G')
 \right\rangle.
\]

因此，前文中的 \(l_t(v)\) 对应论文中的第 \(t\) 轮节点标签；前文中的 \`Compress\` 对应论文把“旧标签加邻居标签多重集合”映射为新标签的压缩函数；前文中的 \(\phi_t(G)\) 对应论文在第 \(t\) 轮对各个 \(\sigma\in\Sigma_t\) 的计数向量。前文写成

\[
 \phi^{(h)}(G)=[\phi_0(G),\ldots,\phi_h(G)]
\]

只是对论文长向量的分块写法，并不是另一种 WL 算法。论文还要求各轮标签集合 \(\Sigma_0,\ldots,\Sigma_h\) 两两不相交；代码通过把轮次 \(t\) 和标签一起作为特征键 \`(t, label)\` 实现了同样的效果。

设一个图为 (G=(V,E))，每个节点 (vin V) 有一个初始离散标签 (l_0(v))。例如，在一般图数据中，标签可以表示原子类型、节点类别或其他离散属性。

在第 (t) 轮，WL 对每个节点收集两类信息：节点上一轮的标签，以及所有邻居上一轮标签组成的多重集合。形式上，可以写成

\[
 s_t(v)=\left(l_t(v),\operatorname{sort}\{l_t(u):u\in N(v)\}\right),
\]

然后把这个结构签名映射成一个新的离散标签：

\[
 l_{t+1}(v)=\operatorname{Compress}(s_t(v)).
\]

这里的 `Compress` 只是把相同的签名映射为相同的整数编码，把不同签名映射为不同编码。它不需要学习参数，也不涉及随机初始化。每一轮只要两个节点的签名完全一致，它们就得到相同的新标签。

直观地说：

- 第 0 轮只看节点自己是什么类型；
- 第 1 轮看“自己是什么类型，以及直接连着哪些类型的节点”；
- 第 2 轮继续看邻居的第 1 轮模式；
- 继续增加迭代轮数，就能观察更大的局部邻域。

对于第 (t) 轮，论文统计每个标签在图中出现了多少次，形成标签直方图 (phi_t(G))。WL subtree kernel 将不同轮次的直方图拼接或相加，得到图的整体特征表示：

\[
 \phi^{(h)}(G)=
 \left[\phi_0(G),\phi_1(G),\ldots,\phi_h(G)\right].
\]

两个图的 WL subtree kernel 可以表示为特征向量内积：

\[
 K_h(G,H)=
 \left\langle \phi^{(h)}(G),\phi^{(h)}(H)\right\rangle.
\]

本项目为消除图规模对内积的直接影响，进一步使用余弦归一化：

\[
 S_h(G,H)=
 \frac{K_h(G,H)}
 {\sqrt{K_h(G,G)}\sqrt{K_h(H,H)}}.
\]

因此，在本项目的定义中，(S_h(G,H)) 位于 ([0,1]) 内，数值越大表示两个图在当前 WL 表示下越接近，数值越小表示越不相似。这个余弦归一化是本项目的相似度报告方式；论文的核心是 WL 标签细化和图核构造，并不要求必须报告余弦形式。

## 3. 本项目如何把 LP/MIP 转换为图

对于一个线性规划或混合整数规划模型

\[
 Ax\ {\leq,=,\geq}\ b,
\]

本项目构造一个变量—约束二部图：

- 每一个决策变量对应一个变量节点；
- 每一个显式线性约束对应一个约束节点；
- 如果变量 (x_j) 在约束 (i) 中的系数非零，即 (A_{ij}\neq 0)，就在变量节点和约束节点之间连一条边。

初始节点标签只编码离散的变量域和约束方向：

| 图节点 | 初始标签 |
|---|---|
| 二进制变量 | `V:B` |
| 一般整数变量 | `V:I` |
| 连续变量 | `V:C` |
| 等式约束 | `R:E` |
| 小于等于或大于等于约束 | `R:I` |

例如，约束

\[
 2x_1+5x_2\leq 10
\]

对应一个 `R:I` 约束节点，并连接到 (x_1) 和 (x_2) 两个变量节点。当前实现使用非零系数决定是否连边，但不把系数的具体数值或符号放进标签。

当前代码中的关键实现位于 [`wl_bipartite.py`](../../wl_bipartite.py)，主要流程是：

1. 读取 LP/MIP 文件并提取约束矩阵的非零结构、变量类型和约束方向。
2. 根据非零矩阵元素创建变量—约束二部图。
3. 使用共享的标签字典，在所有待比较图之间同步压缩每一轮的 WL 签名。
4. 累加第 0 轮到第 (h) 轮的标签计数。
5. 以标签计数向量的余弦值作为图相似度。

代码默认计算 (h=0,1,2,3) 的结果；报告中的主结果使用累计 (h=2)，即使用第 0、1、2 轮的标签。

## 4. 本项目中的比较方式

设 (P) 为一个测试模型，(R_g) 为类别 (g) 的参考模型集合。对每个测试模型，首先计算它与每个候选参考模型的 WL 相似度，再取最近参考：

\[
 S_g(P)=\max_{r\in R_g} S_2(P,r).
\]

因为这里的 (S_2) 越大越相似，所以使用最大值。随后，对同一类别的测试实例集合计算中位数和均值。例如，Mixture 的同类别统计只使用 Mixture 参考集合，不把 Others 参考并入同类别集合。

此外还计算全参考库最近相似度：

\[
 S_{\mathrm{all}}(P)=\max_{r\in R} S_2(P,r),
\]

其中 (R) 包含全部参考模型。全参考库指标回答的是“这个测试模型与所有可用参考中最接近的模型有多相似”，同类别指标回答的是“它与指定类别参考中最接近的模型有多相似”。

## 5. (h=1,2,3) 的含义

输出文件同时保留 (h=1,2,3)，是为了做迭代深度敏感性分析：

| 设置 | 累计使用的 WL 信息 | 结构含义 |
|---|---|---|
| (h=1) | 第 0、1 轮 | 节点类型和直接邻居模式 |
| (h=2) | 第 0、1、2 轮 | 进一步细化的局部连接结构 |
| (h=3) | 第 0、1、2、3 轮 | 更大范围的局部邻域结构 |

主表使用 (h=2)，而不是挑选数值最低的深度。(h=1) 和 (h=3) 用来检验结论是否依赖某一个特定的邻域深度。增加 (h) 会引入更细的局部模式，但不会自动使所有实例的相似度单调下降。

## 6. 这个方法能够比较什么

在当前编码下，WL 主要比较以下结构信息：

- 变量是二进制、整数还是连续变量；
- 约束是等式还是不等式；
- 每个变量连接了多少约束；
- 每个约束连接了多少变量；
- 邻域中变量和约束类型的组合模式；
- 这些局部模式在两个模型中出现的频率。

因此，WL 分数高可以说明两个模型共享较多的变量—约束连接模式。例如，许多模型都会使用“整数数量变量 + 二进制启用变量 + 两条连接约束”的结构，即使它们对应不同的产品、资源或业务场景，WL 仍可能识别出相似的局部模式。

## 7. 这个方法没有比较什么

当前实现明确忽略以下信息：

- 目标函数的方向和系数；
- 约束系数的具体数值和正负号；
- 约束右端项；
- 变量上下界；
- 变量、约束和业务字段的名称；
- 非线性、二次约束或一般约束类型。

因此，WL 相似度不是两个优化模型的完整语义等价性证明，也不是求解难度或求解准确率指标。一个模型可以在 WL 上相似，但拥有不同的成本系数、容量参数、目标函数或业务要求；反过来，两个业务含义相近的模型也可能因为变量域或约束连接方式不同而得到较低分数。

这也是为什么 WL 结果适合用来回答“参考模型和测试模型在显式结构上有多接近”，但不能单独证明方法对新约束、新目标或完全未见过的建模范式具有鲁棒性。审稿人关心的泛化问题仍需要结合成对的扰动实验，例如增加无关约束、改变目标、插入业务约束、拆分数据集和 leave-one-type-out 测试。

## 8. 与 MIPLIB 特征方法的关系

WL 方法和 MIPLIB 2017 的 105 维特征方法解决的是相关但不同的问题。

MIPLIB 方法首先对优化模型进行预处理和归一化，然后从规模、变量类型、目标函数、矩阵系数、边界、约束分类和分解结构等方面提取固定长度的数值特征，再计算特征空间距离。它能使用系数、右端项和更丰富的统计量，但实现流程更复杂，并依赖具体的预处理、约束分类器和分解工具。

WL 方法则把模型的非零模式表示为带类型的二部图，用离散标签细化直接比较局部拓扑结构。它不需要对每一行系数做数值统计，天然不受变量和约束名称影响，并且可以清楚地展示相似度来自第几轮局部结构。代价是：当前编码忽略数值参数、目标函数和变量边界，而且受 1-WL 表达能力限制，某些非同构图可能仍然得到相同或相近的 WL 表示。

因此，本项目把 WL 结果作为一种结构诊断和补充证据，而不是把它宣称为 MIPLIB 105 维特征的替代品或完整的模型等价性检验。

## 9. 论文实验与本项目实验的区别

Shervashidze 等人的原始论文主要在图分类数据集上比较不同图核的分类准确率和运行时间。论文中的图具有离散节点标签，WL 通过标签细化构造 subtree-like features，然后交给核方法进行分类。论文的实验问题是“这些图特征是否有助于区分类别”。

本项目的任务不同：没有训练分类器，而是直接计算 LP/MIP 图之间的归一化相似度，并对每个测试实例寻找最近的参考模型。因而，本项目继承了论文的 WL 标签细化和直方图核思想，但将图定义、节点标签和最终相似度解释适配到了优化模型。
