The product data is stored in the file **`DairyGoodsSalesDataset.csv`**.  
This CSV contains the following columns for each dairy product:

- **Full_Product_Name** – the product identifier (e.g., “Butter_Amul”).  
- **Revenue** – unit revenue (price) for the product.  
- **Demand** – the deterministic demand quantity for the period.  
- **Initial Inventory** – the starting inventory level for the product.

The file has 40 rows, one for each product, and can be used directly to build the revenue‑maximizing order‑fulfillment model.
